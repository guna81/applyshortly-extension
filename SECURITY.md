# Security

Do not post credentials or personal application data in public issues. Report suspected vulnerabilities through the repository's private vulnerability reporting feature if enabled, or a private contact listed on the maintainer's GitHub profile. Do not open a public issue with exploit details while arranging private contact.

The background service worker holds the account credential and performs platform requests. Employer pages must never receive that credential. Profile and application data travel to the configured ApplyShortly server; AI drafts also use the selected provider. Personal provider keys are stored encrypted by the server, not bundled with the extension.

Use a trusted server origin and review filled answers before submitting. Revoke a compromised connection through extension disconnect or the platform's API key settings.
